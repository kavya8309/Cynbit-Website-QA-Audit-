Cynbit Website Quality Audit
Project Overview
This project documents the manual quality audit of the Cynbit website, conducted as part of the Cynbit Technical Assessment.
Website: https://www.cynbit.in
Assessment Date: 20 November 2026
Testing Type: Manual Website Testing
Tester: Kavya Gouravaram
Objective
To evaluate the website's functionality, navigation, content, forms, and responsive behaviour, identify issues, document observations, and provide recommendations for improvement.
Testing Scope
The audit covered:
•	Website loading and navigation
•	Homepage and footer
•	Company, Careers, Social Impact and Products pages
•	BitElevate and QA Testing Lab pages
•	Registration and contact forms
•	Form validation
•	Mobile responsiveness
•	Tablet viewport responsiveness
Test Environment
•	Desktop: Lenovo Laptop, Windows 11, Google Chrome
•	Mobile: Poco M2 Pro, Android, Google Chrome
•	Tablet: Chrome DevTools tablet emulation
•	Testing approach: Manual testing
Test Execution Summary
Metric	Result
Total Test Cases	27
Passed	25
Failed	2
Key Findings
BUG-001 – Contact Inquiry Form Submission Failure
The Contact page inquiry form displayed a generic error message even when valid-looking input values were entered.
OBS-001 – Syllabus Navigation Observation
The syllabus links from specific lab pages opened a generic Unstructured Learning page instead of a clearly identified lab-specific syllabus.
Project Deliverables
1.	QA Audit Report – Testing scope, methodology, environment, results and limitations.
2.	Bug & Issue Report – Documented defect and usability observation.
3.	Manual Test Cases – Excel workbook containing 27 test cases and execution results.
4.	Improvement Recommendations – Prioritized recommendations for website quality improvements.
Testing Limitations
•	Detailed accessibility testing was not performed.
•	Performance measurements and security testing were not performed.
•	Payment completion was not tested.
•	Tablet testing was performed using browser emulation.
•	Broad cross-browser testing was not performed.
Conclusion
The manual audit covered the major website pages, navigation, forms and responsive layouts. A total of 27 test cases were executed, with 25 passing and 2 failing. The identified issue and observation have been documented along with recommendations for improvement.
